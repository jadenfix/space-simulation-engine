# Changelog

## 0.2.0 - 2026-08-16

- Added analytic Minkowski, Schwarzschild, Kerr, and FLRW metrics.
- Added numerical Christoffel symbols and geodesic integration.
- Added weak-field proper time and Schwarzschild 1PN acceleration.
- Added direct N-body leapfrog gravity and collision merging.
- Added 3-D Poisson/SOR gravity lattice and weak-field metric reconstruction.
- Added Parker wind, Parker spiral, motional electric field, plasma diagnostics,
  streams, turbulence, shear, and CME models.
- Added solar, electric, magnetic, and Lorentz spacecraft force models.
- Added rigid-body attitude dynamics and three controller modes.
- Added RK4, adaptive Dormand-Prince 5(4), and velocity Verlet.
- Added Boris/relativistic Boris, electrostatic PIC, Maxwell FDTD, and ideal MHD.
- Added deterministic configs, CSV traces, config hashes, and JSON receipts.
- Added GCC/Clang/CMake/sanitizer/static-analysis validation and machine-readable claims.
- Added a Kerr circular-geodesic executable receipt and an all-force hybrid mission scenario.
